# Queen — сайт студии красоты

Публичный адрес после автодеплоя: `/coding/queen/`.

## Страницы

- `index.php` — главная
- `services.php` — услуги и цены
- `masters.php` — специалисты
- `solarium.php` — солярий
- `contacts.php` — контакты и будущая карта

## Связь с Clientra

Сайт получает публичные данные из:

`/coding/clientra/api/public.php?org=queen-spb`

API отдаёт только публичные поля: имя, специальность, аватар, услуги, цены и ссылки онлайн-записи. Пароли, e-mail, телефоны сотрудников и клиентская база не передаются.

Новый активный сотрудник с назначенными услугами появляется на сайте автоматически. Аватар берётся из Clientra. Если API временно недоступен, сайт показывает демонстрационные карточки.

## Что заменить после получения данных

- точный адрес и режим работы — `contacts.php` и `includes/site.php`;
- телефон и социальные сети — `contacts.php` и подвал в `includes/site.php`;
- реальные интерьерные фотографии — каталог `assets/images/` и визуальные блоки страниц;
- тексты об услугах и студии — соответствующие страницы.
