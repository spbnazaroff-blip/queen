# Queen media library

Server uploads are stored outside Git deployment cleanup and survive future deployments.

`images/unsorted/` — newly uploaded files that have not yet been assigned.

## Video

`video/<direction>/` uses the same service directions, plus `video/unsorted/` for new files.

## File names

Use lowercase Latin letters, numbers and hyphens. Example: `cold-botox-before-after-01.webp`.
